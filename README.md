## 🌟 Overview & Core Principles

Preparing for the **Bihar State Teacher Eligibility Test (STET) Paper II (Computer Science)** and **BPSC TRE PGT** demands deep conceptual mastery, sectional time management, and direct hands-on practice with the authentic **TCS iON CBT** examination interface.

This portal is engineered with strict standards:
1. **100% Authentic Content**: All 14 low-quality predicted mock sets and synthetic templated questions have been permanently eliminated. The platform now features **23 verified papers (1,950 questions)**.
2. **Official PYQs as Gold Standard**: Includes authentic BSEB STET papers (2019, 2020 Re-Exam, 2023, 2025 Shifts 1–4), BPSC TRE 3.0 PGT Computer Science (with 5 options A–E), and official BSEB Art of Teaching pedagogy papers.
3. **Zero Templated Filler**: Every single practice question has been audited for zero templated markers (`Scenario \d+`, `Case \d+`, formulaic distractors).
4. **Balanced Answer Options**: All practice drills feature mathematically balanced answer keys (~25% each across A, B, C, D) without altering factual correctness.
5. **Zero-Dependency Architecture**: Built entirely with semantic HTML5, modern CSS3, and native ES2022+ JavaScript modules—zero React, Vue, Tailwind, bundlers, or runtime npm dependencies.
6. **Local Data Privacy Guarantee**: All test attempts, response states, and scorecards are stored strictly client-side in your browser's `localStorage`. No telemetry or personal information is transmitted to any server.

## 🚀 Key Features

### 🌐 1. Complete Bilingual Engine (English & हिन्दी)
- Instant toggle between **English** and **हिन्दी** across all user interface controls, questions, options, palette legends, and conceptual explanations.
- Question-level segmented control allows toggling between English, Hindi, or **Dual Mode (👁️ Both)** side-by-side.
- Natural Devanagari terminology preserving standard technical terms (`Normalization`, `Deadlock`, `Cache Memory`, `Pipelining`).

### ⏱ 2. Authentic TCS iON CBT Exam Parity
- **Locked Sticky Header**: 150-minute countdown timer pinned permanently to the top of the viewport.
- **Section Switcher**:
  - Section 1: Computer Science (100 Qs / 100 Marks)
  - Section 2: Art of Teaching (30 Qs / 30 Marks)
  - Section 3: General Skills (20 Qs / 20 Marks)
- **Interactive 150-Question Palette**: Full TCS iON color parity (Answered 🟢, Not Answered 🔴, Not Visited ⚪, Marked for Review 🟣, Answered & Marked 🟣🟢).
- **Keyboard Shortcuts**: `1-4` / `A-D` to choose options, `N` for Save & Next, `P` for Previous, `M` for Mark for Review, `C` for Clear, and `L`/`H` for language toggle.
- **5-Option Support**: Full support for BPSC TRE 5-option format (A, B, C, D, E).

### 🔍 3. Accessible Typography Scaling (`A-`, `A`, `A+`)
- Live font scaling (`small`, `normal`, `large`, `xlarge`) accessible in both the lobby and the in-exam header.
- Fully synchronized across question statements, options, explanations, and review solutions with persistent state in `localStorage`.

### 📊 4. Diagnostic Analytics & Category Cutoffs
- **SVG Circular Gauges**: Immediate visual feedback for score percentage, accuracy rate, and question-level pacing.
- **Official Cutoff Evaluation**: Automated evaluation against Bihar STET qualifying standards:
  - General (UR): 75.0 Marks (50%)
  - Backward Class (BC): 68.25 Marks (45.5%)
  - Extremely Backward Class (EBC): 63.75 Marks (42.5%)
  - SC / ST / Divyang / Female: 60.0 Marks (40%)
- **Topic Diagnostic Matrix**: Categorizes performance into Strengths (≥ 75%), Moderate (50–74%), and Focus Areas (< 50%).
- **Interactive Review**: Filter questions by Incorrect, Skipped, or Correct with comprehensive bilingual explanations.

## 🛠️ Developer Guide & Local Setup

### Prerequisites
- Node.js (v18+) for local server and audit scripts.
- Python 3.10+ for the test verification suite.

### Running Locally
```bash
# Clone the repository
git clone https://github.com/your-username/bihar-stet-cs-cbt.git
cd bihar-stet-cs-cbt

# Start a local static server (port 3000)
npm run serve

# Open in browser
# http://localhost:3000
```

### Running Verification Tests
```bash
# 1. Run duplicate questions audit (digit-masked signature comparison)
npm run audit

# 2. Run master test suite (154 checks: DOM, i18n, catalog, CSS, security)
npm test
```

## 🔒 Privacy & Advertising Transparency

- **Local Storage Only**: All candidate attempt records (`BSTET_EXAM_HISTORY`), font size preferences, language choice, and active attempt states are saved strictly in your browser's local storage. No data is stored on remote servers.
- **Advertising Disclosure**: To support server hosting and domain renewal costs, Google AdSense is integrated on lobby and diagnostic screens. Advertisements are never displayed inside the active examination simulation viewport to ensure zero distraction during tests.
